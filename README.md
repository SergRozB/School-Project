This is a game I developed from August 2024 to January 2025 for A level Computer Science coursework, utilising both A star and vector field pathfinding for a top down 2D wave shooter game. 

A star is used by the teammate AI, flow field is used by the zombies. Teammates can be made to follow you, can be sent to specific locations and can be given items by the player. A green square appears over an ally to communicate that you can click the ally to give it orders. The allies spawn in at set waves. Zombies increase with each wave. You gain points for killing zombies and can use these points in between rounds to buy powerups and weapons.

To run the game, run 'ZombieGame.py'. Can run slowly in further rounds and generally very clunky but included a lot of content for an A-level coursework project.
